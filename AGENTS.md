# Open Language Tutor

Follow these steps at the start of each session:

1. **Set Up the Skills**  
   Use the skills in [`.agents/skills/`](.agents/skills/). Install them for this project if supported and not already installed. Otherwise, read them directly.
2. **Read the Profile**  
   Read `learner/profile.md`. Update it as you learn what helps the learner across languages.
3. **Choose a Language**  
   Ask which language the learner wants to learn. If they have already named one, use that language.
4. **Open the Language Record**  
   If `learner/languages/<code>.md` exists, read it and continue. Otherwise, ask the learner to estimate their ability in the language. Use that estimate to choose a short, low-pressure conversation or activity. Create the record from [the template](learner/languages/TEMPLATE.md) and record only the abilities the learner demonstrates.
5. **Lead Practice**  
   Use the relevant skills to guide the lesson. Suggest an activity if the learner is unsure what to do. Update the language record when there is something worth keeping.
